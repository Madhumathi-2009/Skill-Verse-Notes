### 📘 About This Repo
This repository contains our handwritten class notes from **Skill Verse - GitHub Essentials**. 
Made for beginners, by beginners. Simple examples and easy explanations.

<img src="https://user-images.githubusercontent.com/73097560/115834477-dbab4500-a447-11eb-908a-139a6edaec5c.gif">

### 📖 What's Inside?

| Day | Topic | What You Will Learn |
|-----|-------|---------------------|
| **DAY 1** | **GitHub Essentials**<br>[📄 View Notes](./Skill%20verse-Notes-Day%201.pdf) | - What is Git & GitHub?<br>- What is Version Control<br>- Git vs GitHub |
| **DAY 2** | **HTML Webpage**<br>[📄 View Notes](./Skill%20verse-Notes-Day%202.pdf) | - How to create HTML webpage<br>- Connect Git with VS Code<br>- How to publish on GitHub |
| **DAY 3** | **Repository Basics**<br>[📄 View Notes](./Skill%20verse-Notes-Day%203.pdf) | - What is a Repository?<br>- How to create a repo?<br>- Public / Private visibility |
| **DAY 4** | **Markdown Docs**<br>[📄 View Notes](./Skill%20verse-Notes-Day%204.pdf) | - What is Markdown?<br>- Table, Lists, Checkbox<br>- How to build README |
| **DAY 5** | **Collaboration**<br>[📄 View Notes](./Skill%20verse-Notes-Day%205.pdf) | - How to collaborate<br>- Pull Request & Code Reviews<br>- Open Source Ethics |
| **DAY 6** | **Professional GitHub Portfolio**<br>[📄 View Notes](./Skill%20verse-Notes-Day%206.pdf) | - What is GitHub pages?<br>- Personal Portfolio<br>- Digital Resume |
